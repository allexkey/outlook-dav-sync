Connect Outlook for Mac to CalDAV and CardDAV

Outlook for Mac cannot add CalDAV or CardDAV accounts — even though Apple Calendar can. outlook-dav-sync is a free, open-source tool that keeps an Outlook calendar and address book in two-way sync with your own server. No Exchange, no Microsoft 365 needed.

Get it on GitHub Install guide

Install in one command

git clone https://github.com/allexkey/outlook-dav-sync.git
cd outlook-dav-sync && ./install.sh

The installer asks for your server address and username, stores the password in the macOS Keychain, shows a dry run of what would change, and then syncs every 3 minutes in the background while Outlook is open.

What it does

Calendar, both ways

Events, all-day events, recurring series and their exceptions.

Contacts, both ways

Names, companies, phones, e-mails, addresses and notes.

Keeps server data

Attendees, organizer, alarms and contact photos on the server are preserved when you edit in Outlook.

Safe by default

Full backup on first run, a backup before every delete, and a stop if a run would delete too much.

Password in Keychain

Never written to a file. Plain HTTPS to your own server, nothing else.

No dependencies

Python standard library and Outlook's own scripting support. MIT licensed.

Works with

Tested: cPanel CalDAV/CardDAV (cpdavd, port 2080) with Legacy Outlook 16.115 on macOS.
Should work: any standards-compliant server with username/password login — Nextcloud, Radicale, Baïkal, SOGo, DAViCal, Fastmail, mailbox.org. Reports are welcome in GitHub issues.

No support — use as is

This tool was built for my own setup, where it has been tested and is in daily use. It is shared as is, without support or warranty. Everyone who installs it uses it at their own risk and keeps their own backups. Issues and pull requests are welcome, but there is no promise of a reply or a fix.

Questions

Does Outlook for Mac support CalDAV?

No. Outlook for Mac supports Exchange, Microsoft 365, Outlook.com, Google and iCloud accounts, but not generic CalDAV or CardDAV servers. This tool fills that gap by syncing a local Outlook calendar and address book with your server.

Does it work with New Outlook for Mac?

Not yet. New Outlook cannot be scripted, so the tool needs Legacy Outlook (Outlook menu → Legacy Outlook).

Is CalDav Synchronizer available for Mac?

No, CalDav Synchronizer is a Windows add-in. On the Mac, outlook-dav-sync covers the same need for calendar and contacts.

What happens if I edit the same event in two places?

The server version wins and the Outlook version is saved as a backup file, so nothing is lost silently.

Does it sync reminders and tasks?

No. Reminders stay local on each side, and tasks (VTODO) are not synced.
